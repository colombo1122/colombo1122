# Tetris — גרסת דסקטופ (Python + pygame-ce)

משחק טטריס שרץ בחלון משלו על המחשב, עם צלילים ומוזיקת רקע.

## דרישות

- Python 3.9 ומעלה (נבדק על 3.14)
- חבילה אחת: `pygame-ce`

## התקנה והרצה

```powershell
python -m venv venv
venv\Scripts\Activate.ps1
pip install pygame-ce
python tetris.py
```

## מקשים

| מקש | פעולה |
|---|---|
| ← → | הזזה |
| ↑ או X | סיבוב |
| Z | סיבוב נגד כיוון השעון |
| ↓ | ירידה מהירה |
| רווח | נפילה מיידית |
| P / Esc | השהיה |
| M | מוזיקה פעילה/כבויה |
| N | צלילים פעילים/כבויים |
| Enter | התחלה / משחק חדש |

## הערות

- כל הצלילים נוצרים בזמן ריצה (Web-Audio-style synth) — אין קבצי שמע חיצוניים
- מנגינת הרקע היא Korobeiniki, המנגינה הקלאסית של טטריס
- הממשק באנגלית מסיבות תמיכה של פונטים ב-RTL ב-pygame
